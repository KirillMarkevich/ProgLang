```
C++: k e
```

### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```

*Объяснение вычислений (unsigned short имеет размер 2 байта, диапазон от 0 до 65535):*

1. `y = x + x`; 40000 + 40000 = 80000. Происходит переполнение типа `unsigned short`. Результат вычисляется по модулю $2^{16} = 65536$:

   $80000 \mathbin{\bmod} 65536 = 14464$

2. `z = x * 2`; $40000 \cdot 2 = 80000$. Аналогично, из-за переполнения `z` становится равным 14464.

3. `y = y - x`; $14464 - 40000 = -25536$. Происходит "нижнее" переполнение (underflow). Результат приводится к беззнаковому диапазону:

   $-25536 + 65536 = 40000$

   Поэтому $x + x - x = x$ всегда выполняется, так как вычитание в беззнаковой арифметике в точности обращает сложение по модулю.

4. `z = z / 2`; $14464 / 2 = 7232$.

   Поскольку на этапе умножения старший бит информации уже был безвозвратно потерян из-за переполнения, обычное деление на 2 не может восстановить исходное число. Таким образом, $(x \cdot 2) / 2 \neq x$.

*Программа выведет: 40000 7232*

### Задание 8 **(2)**

*Найдите результаты вычисления следующих выражений без использования компьютера
или калькулятора. Процесс вычислений должен быть отображен в отчете.*
* `(1000 & 100) << 10`
* `(1000 >> 4) & 15`
* `~1234 + 1234`
* `(1000 ^ 500) & 63`
* `(100 << 3) + (100 >> 3)`

1. `(1000 & 100) << 10`

   $1000_{10} = 1111101000_2$, $100_{10} = 1100100_2$.

   Побитовое И (`&`): в результате останутся только общие биты $\rightarrow 0001100000_2 = 96_{10}$.

   Сдвиг влево на 10: $96 \cdot 2^{10} = 96 \cdot 1024 = \mathbf{98304}$.

2. `(1000 >> 4) & 15`

   $1000_{10} = 1111101000_2$. Сдвиг вправо на 4 убирает 4 младших бита $\rightarrow 111110_2 = 62_{10}$.

   $62 \mathbin{\&} 15 \rightarrow 111110_2 \mathbin{\&} 001111_2 = 001110_2 = \mathbf{14}$.

3. `~1234 + 1234`

   По определению дополнительного кода инверсия числа $\sim x$ равна $(-x - 1)$.

   Следовательно, $(-1234 - 1) + 1234 = \mathbf{-1}$.

4. `(1000 ^ 500) & 63`

   Операция `& 63` (где $63 = 111111_2$) оставляет только 6 младших бит результата. Значит, нам важны только 6 младших бит чисел 1000 и 500.

   Младшие 6 бит 1000 ($1111101000_2$) — это $101000_2$ (40).

   Младшие 6 бит 500 ($111110100_2$) — это $110100_2$ (52).

   Исключающее ИЛИ (`^`): $101000_2 \oplus 110100_2 = 011100_2 = \mathbf{28}$.

5. `(100 << 3) + (100 >> 3)`

   $100 \ll 3 = 100 \cdot 8 = 800$.

   $100 \gg 3 = 100 / 8 = 12$ (целочисленное деление).

   Сумма: $800 + 12 = \mathbf{812}$
