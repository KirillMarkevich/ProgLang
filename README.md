## Задание 2
### Сообщения об ошибках
C++: error: expected ';' after expression и error: use of undeclared identifier 'b'.
Python: Программа выполняется без ошибок.

### Разбиение на токены
C++: int, main, (, ), {, int, a, =, 1, ,, b, =, 2, ;, int, c, =, a, ++, b, ;, return, 0, ;, }
Python: a, =, 1, \n, b, =, 2, \n, c, =, a, =, +, +, b.

### Объяснение
В C++ компилятор использует правило «максимального поглощения». Он видит + после a и пытается захватить как можно более длинный токен — получается оператор инкремента ++. После этого выражение принимает вид a++ b, что является синтаксической ошибкой.
В Python оператора постфиксного инкремента ++ не существует. Поэтому интерпретатор разбирает выражение как два унарных плюса перед переменной b: a + (+b). Это синтаксически корректная математическая операция.


## Задание 3
### Результаты работы
После выполнения программы значения переменных будут равны:
a = 2 (так как сработал постфиксный инкремент a++)
b = 2 (не изменилось)
c = 3 (вычисляется как 1 + 2)

### Токены выражения
int, c, =, a, ++, +, b, ;

### Объяснение работы
По правилу максимального поглощения компилятор группирует первые два плюса в токен постфиксного инкремента ++, а третий плюс становится бинарным оператором сложения. Выражение эквивалентно: c = (a++) + b. Значение a берется для сложения с b, получается 3. После этого значение a увеличивается на 1.

### Изменение разбиения пробелами
Да, пробелами можно изменить логику:
1.  int c = a + ++b; — теперь токены: a, +, ++, b. Сначала сработает префиксный инкремент b, затем сложение. Результат: a=1, b=3, c=4.
2.  int c = a + + + b; — три унарных/бинарных плюса. Результат: a=1, b=2, c=3.


## Задание 4
Круглые () и квадратные [] скобки являются операторами тогда, когда они выполняют конкретное действие над операндами. Если они служат лишь для группировки выражений или являются частью синтаксиса конструкций, они операторами не являются.


Круглые () 
Являются оператором: 
Вызов функции/функтора: foo(x); Приведение типов (в C): int a = (int)3.14;
Не являются оператором: 
Группировка операций: int a = (x + y) * z; Синтаксис конструкций: if (x > 0) { ... }

Квадратные []
Являются оператором: 
Индексация: int element = array[i];
Не являются оператором:
Объявление массива: int array[10]; Захват контекста в лямбдах C++: [x](int y) { return x + y; };


## Задание 5
print(*map(sum,zip(
    *[map(int,input().split()) for i in (1,2,3)]
    )))

Ключевые слова: for, i
Идентификаторы: print, map, sum, zip, int, input, split, i
Литералы: 1, 2, 3
Операторы: *

### Классификация идентификаторов
Переменные: i.
Имена встроенных функций/классов: print, map, sum, zip, int, input.
Имена методов: split.

### Вызываемые функции и их параметры
1.  input() — без параметров. Возвращает строку, введенную пользователем.
2.  split() — вызывается у результата input(). Без явных параметров.
3.  int — используется как функция-преобразователь внутри map.
4.  map(int, <результат split>) — параметры: функция int и итерируемый объект строк.
5.  zip(*[...]) — параметры: три распакованных списка чисел.
6.  sum — используется как функция внутри внешнего map.
7.  map(sum, <результат zip>) — параметры: функция sum и итератор столбцов.
8.  print(*<результат map>) — параметры: распакованные суммы столбцов.

### Что делает программа и как работает
Программа считывает три строки чисел (матрицу 3xN), транспонирует ее и выводит суммы ее столбцов.
1.  Генератор списков for i in (1,2,3) выполняет итерацию 3 раза. Каждый раз через input().split() считывается строка чисел и с помощью map(int, ...) превращается в список целых чисел. Получается список из трех списков.
2.  * перед списком в zip(*...) распаковывает его, передавая в zip 3 строки как отдельные аргументы. zip группирует элементы с одинаковыми индексами.
3.  Внешний map(sum, ...) применяет функцию sum к каждому полученному столбцу.
4.  print(*...) распаковывает итоговые суммы и выводит их через пробел.


## Задание 6
В C++ комментарии записываются двумя способами:
1.  Строчные: // комментарий до конца строки
2.  Блочные (многострочные): /* комментарий */

### Разбор примеров
1.  cout<<"Hello /* Это комментарий */ world";
    	Синтаксически верен. Текст /* ... */ находится внутри строкового литерала, поэтому компилятор воспринимает его как обычную часть строки. Выведет: Hello /* Это комментарий */ world.
2.  // /*
    Это комментарий
    */
    	Ошибка трансляции. Первая строка начинается с //, поэтому /* игнорируется. На следующей строке текст Это комментарий компилятор пытается выполнить как код и выдает ошибку.
3.  /* Я комментирую программы /* комментарий */ */
    	Ошибка трансляции. Блочные комментарии в C++ не могут быть вложенными. Первый /* закрывается ближайшим */. Оставшийся в конце текста фрагмент */ вызывает ошибку компиляции.
4.  // Я комментирую программы /* комментарий */
    	Синтаксически верен. Вся строка после // считается комментарием и игнорируется, включая символы /* и */.
5.  /* Я комментирую свои программы
    // Это комментарий до конца строки */
    */
    	Ошибка трансляции. Блочный комментарий /* на первой строке закрывается символами */ в конце второй строки. Последняя строка */ оказывается лишней и вызывает ошибку.


## Задание 7
Согласно стандарту C++ (N4659), определено 3 инструкции циклов (*iteration-statement*).

1.  Первый вид — цикл while (с предусловием).
    	Строка правила:* while ( condition ) statement
    	Описание:* Ключевое слово while, за которым в круглых скобках следует условие condition, а затем исполняемая инструкция statement. Цикл выполняется, пока условие истинно.
    	Пример:
        while (x < 5) {
            x++;
        }

2.  Второй вид — цикл do-while (с постусловием).
	Строка правила: do statement while ( expression ) ;
    	Описание: Ключевое слово do, далее тело цикла statement, затем ключевое слово while, в круглых скобках выражение-условие expression и обязательная точка с запятой ;. Цикл гарантированно выполняется хотя бы один раз, проверка идет после итерации.
    	Пример:
        do {
            cin >> token;
        } while (token != 0);

3.  Третий вид — традиционный цикл for и for по диапазону.
  	Строка правила: for ( for-init-statement condition_opt ; expression_opt ) statement
 	Описание: Ключевое слово for, в круглых скобках: инструкция инициализации, затем опциональное условие выполнения, точка с запятой, и опциональное выражение изменения счетчика. Далее следует инструкция тела цикла.
    	Пример:
        for (int i = 0; i < 10; ++i) {
            cout << i;
        }

	Строка правила (range-for): for ( for-range-declaration : for-range-initializer ) statement
	Описание: Ключевое слово for, в круглых скобках объявление переменной диапазона, двоеточие и сам итерируемый диапазон. Далее — тело цикла.
	Пример:
        for (int element : array) {
            sum += element;
        }


## Задание 8
Абстрактное синтаксическое дерево для выражения a = -x+y*(z-1); строится с учетом приоритета операторов:


          [=]
         /   \
       (a)   [+]
            /   \
          [-]   [*]
          /     / \
        (x)   (y) [-]
                    / \
                  (z) (1)


Структура дерева:
	Корень дерева — оператор присваивания =. Левый лист — переменная a.
	Правая часть — оператор сложения +, связывающий унарный минус и операцию умножения.
	Левый потомок + — унарный минус -, примененный к x.
	Правый потомок + — оператор умножения *. Его операнды: переменная y и результат выражения в скобках.
	Выражение в скобках (z-1) раскрывается как оператор вычитания - с операндами z и 1.
