### Задание 4 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = list(range(10))
b = [a.pop() - x for x in a]
print(*b)
```
*Объясните, почему список* **b** *получился именно таким.*


**Решение:**

Изначально `a = [0, 1, 2, ..., 9]`. Итератор списка в выражении `[a.pop() - x for x in a]` проходит по списку, а `a.pop()` каждый раз удаляет последний элемент текущего списка. Поэтому вычисляются выражения `9 - 0`, `8 - 1`, `7 - 2`, `6 - 3`, `5 - 4`. Список сокращается во время обхода, поэтому выполняется только пять итераций.

В результате `b` равен:
```python
[9, 7, 5, 3, 1]
```


### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*


**Решение:**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<long long> v(n);
    for (auto &x : v) {
        cin >> x;
    }

    if (!v.empty()) {
        const long long last = v.back();
        for (auto &x : v) {
            x += last;
        }
    }

    int positive = 0;
    int negative = 0;
    for (const auto &x : v) {
        if (x > 0) ++positive;
        else if (x < 0) ++negative;
    }

    cout << "Положительных: " << positive << '\n';
    cout << "Отрицательных: " << negative << '\n';
    return 0;
}
```


### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*


**Решение:**

Два основных различия:

1. `from` и `to` вычисляются один раз при создании `__i` и `__n`. В обычном цикле `for (int i = from; i < to; ++i)` выражение `to` проверяется заново при каждой проверке условия.
2. В `forc` переменная `i` объявлена как `const int&`, то есть является константной ссылкой на внутреннюю переменную `__i`. Изменять `i` напрямую нельзя, тогда как обычный счётчик `for` можно изменять.

**Программа 1 — отличие в вычислении верхней границы:**
```cpp
#include <iostream>
using namespace std;

int main() {
    int to = 3;
    {
        int __i = 0, __n = to;
        for (const int &i = __i; i < __n; __i++) {
            cout << i << ' ';
            --to;
        }
    }
    cout << '\n';
}
```
Вывод: `0 1 2`, потому что `__n` сохраняет начальное значение `3`.

Для сравнения, обычный цикл:
```cpp
#include <iostream>
using namespace std;

int main() {
    int to = 3;
    for (int i = 0; i < to; ++i) {
        cout << i << ' ';
        --to;
    }
    cout << '\n';
}
```
Вывод: `0 1`. В обычном цикле значение `to` меняется и повторно проверяется на каждой итерации.

**Программа 2 — отличие в изменяемости счётчика:**
```cpp
int to = 5;
{
    int __i = 0, __n = to;
    for (const int &i = __i; i < __n; __i++) {
        ++i;
    }
}
```
В обычном цикле `for` выражение `++i` внутри тела допустимо.


### Задание 7 **(2)**

*Напишите программу на языке* **Python** *для проверки того, что все числа во введенной 
последовательности неотрицательные. Если в цикле будет найдено отрицательное число, цикл должен
прерваться и вывести найденное число. Если отрицательных чисел нет, то вывести некоторое сообщение об этом.*

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*


**Решение:**

**Python**
```python
numbers = [int(x) for x in input().split()]

for x in numbers:
    if x < 0:
        print("Найдено отрицательное число:", x)
        break
else:
    print("Все числа неотрицательные")
```

**C++**
```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int n;
    cin >> n;
    vector<int> numbers(n);

    for (int &x : numbers) {
        cin >> x;
    }

    bool found = false;
    for (int x : numbers) {
        if (x < 0) {
            cout << "Найдено отрицательное число: " << x << '\n';
            found = true;
            break;
        }
    }

    if (!found) {
        cout << "Все числа неотрицательные\n";
    }
    return 0;
}
```
В Python цикл `for` имеет конструкцию `else`, которая выполняется, если цикл завершился без `break`. В C++ такого `else` у цикла нет, поэтому используется логическая переменная `found`, чтобы запомнить, было ли найдено отрицательное число.
